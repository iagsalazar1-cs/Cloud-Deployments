# Cloud Deployments

### About this Repository

This repository documents practical exercises and lab builds focused on cloud infrastructure provisioning, security controls, and remote management across cloud service providers.

---

### Projects

- [**EC2 Windows Server Instance Creation:**](https://github.com/iagsalazar1-cs/Cloud-Deployments/tree/main/01-EC2-Windows-Server-Instance-Creation) Outlines the provisioning and administrative setup of an Amazon EC2 Windows Server 2016 instance on AWS, configuring security group inbound rules, key pair authentication, and remote access via RDP.
